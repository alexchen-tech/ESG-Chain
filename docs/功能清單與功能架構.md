版本：v1.0　最後更新：2026-07-23
本文件直接依現行程式碼（路由、選單、後端服務）整理，反映系統目前的實際狀態。

## 一、功能架構總覽

### 1.1 三層服務架構

```text
esgchain-web（Vue 3 + Vite + Pinia）  Port 5173
        │  /api → 業務流程、狀態機、CRUD
        ▼
esgchain-api（Laravel 12 + MySQL 8.4） Port 8081
        │  /ai → 評分、PCF 計算、AI 推論
        ▼
esgchain-ai（FastAPI + PostgreSQL + Celery + Redis） Port 8000
```

### 1.2 前端功能模組架構（依側邊欄選單分組）

```text

│
├─ 永續倡議問卷（SAQ）
│   ├─ 審核管理 / 評核專案 / 評核系列 / 評核範本 / 題目庫
│
├─ 商品合規管理
│   ├─ 合規看板 / 銷售產品 / 生產批號 / 出口審查
│
├─ 風險稽核

```

### 1.3 核心資料鏈架構

系統以「物料—供應商—產品—批號」四段關係為永續情報的骨幹：

```text
① 物料 → 供應商（主/輔）      MaterialItem──(material_item_suppliers)──>Supplier
② 物料類別 → 合規文件標記     MaterialGroup.required_doc_types
③ 物料 → BOM → 產品           MaterialItem──(product_bom_lines)──>SalesProduct
④ 批號 → 選供應商 → 合規調查   ProductionBatch──(raw_material_origins.supplier_id)──>Supplier
                              合規調查 = ②必備文件類型 ∩ 該批次實際供應商的文件狀態
```

四段關係對應三個資料層級：**物料層**（核可清單，低頻變動）→ **產品層**（BOM 組成，中頻變動）→ **批號層**（實際供應商，逐批可能不同，高頻變動）。

## 二、功能清單

### 2.1 儀表板

| 功能 | 路由 | 說明 |
|---|---|---|
| 首頁儀表板 | `/dashboard` | 供應商風險分佈、SAQ 完成率、CAP 待辦數量、近期風險事件卡片 |
| 永續風險活動時間軸 | `/dashboard/activity` | 時間軸型事件紀錄檢視 |

### 2.2 供應商管理

| 功能 | 路由 | 說明 |
|---|---|---|
| 供應商清單 | `/suppliers` | 依 Tier、風險等級、國家、分組篩選；供應商比較（最多 4 家） |
| 供應鏈連結圖 | `/suppliers/network` | 供應商關聯圖譜視覺化 |
| 供應商匯入 | `/suppliers/import` → `/suppliers/import/review` | CSV 上傳、比對預覽、確認寫入（ERP 欄位覆蓋，ESG-Chain 欄位不受影響） |
| 供應商詳情 | `/suppliers/:id` | 基本資料、SAQ 歷史、風險評估、合規文件、關聯 BOM |
| 供應商合規詳情（合規視角） | `/compliance/suppliers/:id` | 供應商合規文件為主的檢視角度 |
| 合作狀態轉換 | 供應商詳情頁內操作 | `onboarding_stage`（active/suspended/terminated）狀態機轉換，留稽核日誌；ERP `status` 唯讀不可由此變更 |

### 2.3 物料管理

| 功能 | 路由 | 說明 |
|---|---|---|
| 物料主檔清單 | `/materials/items` | ERP 同步料號清單 |
| 物料匯入 | `/materials/items/import` | CSV 批次匯入 |
| 物料詳情 | `/materials/items/:id` | 碳排資料庫、來源供應商分布、**核可供應商清單（主/備）** |
| 物料群組 | `/materials/groups` | 物料分類管理，維護 `required_doc_types`（該類物料的供應商合規文件要求） |
| 碳排請求 | `/materials/pcf-requests` | 向供應商發起碳排數據請求 |

**核可供應商清單**（`material_item_suppliers`）：每個物料登記一次主/備供應商，所有使用此物料的產品共用；供應商須 `onboarding_stage = certified` 方可列入；可「套用至 BOM 明細」將核可清單寫入特定產品的供應商登記。

### 2.4 永續倡議問卷（SAQ）

| 功能 | 路由 | 說明 |
|---|---|---|
| 問卷發送 | `/questionnaires/send` | 對供應商發送 SAQ 問卷 |
| 審核管理 | `/questionnaires/review` → `/questionnaires/review/:id` | 問卷回覆審核、AI 評分結果檢視 |
| 評核專案 | `/questionnaires/projects` → `/:id` | 評核專案管理（一次評核活動的範圍與進度） |
| 評核系列 | `/questionnaires/series` → `/:id` | 問卷系列版本管理 |
| 評核範本 | `/questionnaires/templates` → `/settings/questionnaire-templates/:id` | 問卷題型範本設計 |
| 題目庫 | `/settings/question-bank` | 題目主檔管理 |

### 2.5 商品合規管理

| 功能 | 路由 | 說明 |
|---|---|---|
| 合規看板 | `/compliance` | 商品合規總覽儀表板 |
| 銷售產品清單 | `/sales-products` | 唯一產品主檔（原 TradeGood/BuyerProduct 已合併） |
| 銷售產品匯入 | `/sales-products/import` | CSV 批次匯入 |
| 銷售產品詳情 | `/sales-products/:id` | 分頁：基本資訊／法規適用／BOM 明細（含上游供應商彙總）／生產批次／PCF 快照／循環經濟／碳排回報 |
| 生產批號清單 | `/compliance/production-batches` | 批號列表，Drawer 快速編輯原料溯源 |
| 生產批號詳情 | `/compliance/production-batches/:id` | 分頁：批號資訊／碳足跡與循環經濟／有害物質揭露／供應鏈合規（製程地點＋合規文件＋原料溯源＋**批次實際供應商選定**） |
| 出口審查 | `/compliance/export-reviews` | 跨批號彙總清單（含完全未審查的批號），可展開列內面板直接執行審查、產出 DDS 草稿、查看批次護照 JSON |

**批次實際供應商選定**：原料溯源新增時可指定對應 BOM 物料，系統帶出該物料的核可供應商清單供選擇，作為批次的「最後合規確認」。

## 三、後端服務功能架構（esgchain-api 核心邏輯）

### 3.1 合規判斷服務

| 服務 | 職責 |
|---|---|
| `ProductUpstreamResolver` | 從 BOM＋核可清單反推「產品/批次的上游供應商是誰」，供下列服務共用同一套邏輯 |
| `MarketComplianceChecker` | 商品在指定市場的合規文件比對（市場規則 × 供應商文件狀態） |
| `BatchExportReviewService` | 批號 × 市場出口合規審查引擎：文件規則、EUDR/UFLPA 溯源、批次 PCF、DPP 六類欄位完整度 |
| `ExportReviewQueueService` | 跨批號的出口審查清單查詢（含尚未審查的批號） |
| `BatchPassportService` | 批次當下所有已知資料的完整彙總（唯讀 JSON，概念對應未來 DPP 對接） |

### 3.2 資料模型服務

| 服務/Controller | 職責 |
|---|---|
| `MaterialItemSupplierController` | 物料核可供應商清單維護（新增/移除/主備切換/套用至 BOM 行） |
| `RawMaterialOriginController` | 批次原料溯源與實際供應商選定 |
| `ProductBomLineService` | BOM 明細管理，含循環參照防呆（`assertNoCycle()`） |
| `CapAutoGenerationService` | 依 SAQ 低分項自動產生 CAP 矯正行動 |
| `ErpSyncService` | ERP 資料同步（供應商/物料/BOM/銷售產品），欄位歸屬依 CLAUDE.md 規則區分 ERP 擁有與 ESG-Chain 擁有欄位 |

### 3.3 風險計算

| Job/Observer | 職責 |
|---|---|
| `CalculatePathRiskJob` | 出口市場合規義務缺口的路徑風險分數計算 |
| `SupplierComplianceDocPathRiskObserver` | 供應商合規文件變動時，重新計算受影響產品的路徑風險快取 |

### 3.4 esgchain-ai（計算密集任務）

| 職能 | 說明 |
|---|---|
| SAQ 評分 | 依評分模型計算供應商永續評分 |
| PCF 計算 | 產品/批次碳足跡計算（Celery 非同步） |
| 風險評估 | 供應商六維風險評估模型 |
