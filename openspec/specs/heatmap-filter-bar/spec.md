## ADDED Requirements

### Requirement: 熱圖篩選列（Filter Bar）
`SixDimHeatmapView.vue` SHALL 在維度排序列上方提供篩選列，支援國家多選與風險等級快篩，所有篩選邏輯均在前端 computed 處理，不發起新 API 請求。

#### Scenario: 國家多選篩選
- **WHEN** 使用者從國家下拉選單選取一個或多個國家代碼（如 CN、TW）
- **THEN** 表格僅顯示 `country_code` 符合所選國家的供應商列
- **AND** 選取標籤顯示於篩選列，每個標籤附帶「×」可單獨移除
- **AND** 未選取任何國家時顯示全部

#### Scenario: 風險等級快篩
- **WHEN** 使用者選擇風險等級篩選選項
- **THEN**「全部」：顯示所有供應商（預設）
- **AND**「需關注」：僅顯示 `is_critical: true` 的供應商（任一維度低於閾值）
- **AND**「高風險」：僅顯示任意 ≥ 3 個維度低於閾值的供應商

#### Scenario: 篩選計數提示
- **WHEN** 任一篩選條件啟用
- **THEN** 篩選列右側顯示「顯示 X / 27 家」字樣（X 為篩選後數量）
- **AND** 表格為空時顯示「無符合條件的供應商」空狀態提示

#### Scenario: 清除所有篩選
- **WHEN** 使用者點擊「清除篩選」按鈕
- **THEN** 所有篩選條件重置，恢復顯示全部供應商
- **AND**「清除篩選」按鈕僅在有任一篩選條件啟用時顯示
